2. `prompts.yaml` contains a `generation` section with `system` and `user` Jinja2 templates that enforce `[Article X, Section Y]` citation format

5. `GenerationPipeline.answer(query)` runs end-to-end: retrieve → prompt → generate → validate citations

7. Models are pulled: `ollama pull llama3.1:8b` completes successfully

**PromptBuilder.build() logic:**
```python
def build(self, query: str, chunks: list[Chunk]) -> tuple[str, str]:
    context_parts = []
    for i, chunk in enumerate(chunks):
        context_parts.append(
            f'<chunk id="{chunk.id}" article="{chunk.article}" '
            f'section="{chunk.section}">\n{chunk.text}\n</chunk>'
        )
    context = "\n\n".join(context_parts)
    user_prompt = self.user_template.render(context=context, query=query)
    # Truncate with tiktoken
    enc = tiktoken.get_encoding("cl100k_base")
    tokens = enc.encode(user_prompt)
    if len(tokens) > self.max_tokens:
        tokens = tokens[:self.max_tokens]
        user_prompt = enc.decode(tokens)
    system_prompt = self.system_template.render()
    return system_prompt, user_prompt
```

**Generator.generate() core logic:**
```python
def generate(self, system_prompt: str, user_prompt: str) -> str:
    models_to_try = [self.model, self.fallback]
    for model in models_to_try:
        try:
            response = chat(
                model=model,
                messages=[
                    {"role": "system", "content": system_prompt},
                    {"role": "user", "content": user_prompt},
                ],
                options=Options(
                    temperature=0.1,
                    num_ctx=4096,
                    num_predict=1024,
                ),
            )
            return response.message.content
        except ResponseError as e:
            if e.status_code == 404 and model == self.model:
                logger.warning(f"Model {model} not found, trying fallback {self.fallback}")
                continue
            raise
        except ConnectionError:
            raise ConnectionError(
                "Cannot connect to Ollama. Ensure Ollama is running (ollama serve)"
            )
    raise RuntimeError(f"Neither {self.model} nor {self.fallback} available")
```

**Citation extraction regex details:**
- Pattern: `r'\[(Article)\s+((?:[IVXLCDM]+|\d+)),\s*Section\s+(\d+(?:\([a-z]\))?)\]'`
- Group 1: "Article" (literal)
- Group 2: Roman numerals (I, II, III, IV, V, VI, etc.) OR Arabic digits (1, 2, 3...)
- Group 3: Section number with optional letter subsection: "5", "5(a)", "12(b)"
- Case-insensitive via `re.IGNORECASE`
