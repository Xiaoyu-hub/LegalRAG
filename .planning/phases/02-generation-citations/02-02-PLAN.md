**RelevanceJudge.evaluate() core logic:**
```python
def evaluate(self, query: str, answer: str, chunks: list[Chunk]) -> dict:
    source_text = "\n\n".join(
        f"[Article {c.article}, Section {c.section}]: {c.text[:200]}"
        for c in chunks if c.article and c.section
    )
    user_prompt = self.judge_user_template.render(
        query=query, answer=answer, sources=source_text
    )
    try:
        response = chat(
            model=self.model,
            messages=[
                {"role": "system", "content": self.judge_system_template.render()},
                {"role": "user", "content": user_prompt},
            ],
            options=Options(temperature=0.0),
            format="json",
        )
        result = json.loads(response.message.content)
        score = int(result.get("score", 0))
        if score < 1 or score > 5:
            raise ValueError(f"Score {score} out of range 1-5")
        return {"score": score, "reasoning": result.get("reasoning", ""), "error": None}
    except Exception as e:
        return {"score": None, "reasoning": "", "error": str(e)}
```

  - `__init__(self, retrieve_fn=None, generation_pipeline=None, judge=None)` — add optional generation pipeline and judge
  - `citation_precision(citations: list[Citation]) -> float` — static method:
    ```python
    @staticmethod
    def citation_precision(citations: list) -> float:
        if not citations:
            return 1.0
        valid = sum(1 for c in citations if c.valid)
        return valid / len(citations)
    ```
  - `evaluate_generation(self, queries: list[dict] = None, output_path: str = None) -> dict`:
    - If no queries, use TEST_QUERIES
    - For each query:
      1. Call `self.generation_pipeline.answer(query["query"])`
      2. Extract citations from pipeline's last output
      3. Compute citation_precision
      4. If RelevanceJudge available, call judge.evaluate()
      5. Build per-query result dict
    - Aggregate: compute average_citation_precision across queries
    - Format: `{"average_citation_precision": float, "average_relevance_score": float|None, "per_query": [...], "total_queries": int, "evaluated_at": str}`
    - Write to output_path if provided (JSON)

  - `format_generation_results(results: dict) -> str` — static method for readable output

  **CRITICAL:** Do NOT modify existing methods (precision_at_k, recall_at_k, evaluate_query, evaluate_all). Only ADD new methods.
