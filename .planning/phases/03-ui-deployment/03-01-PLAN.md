```python
with st.sidebar:
    st.markdown("## ⚖️ LegalRAG")
    st.caption("v1.0")
    
    # Navigation radio (D-10) — default to "Documents" on first visit
    if "nav_page" not in st.session_state:
        st.session_state.nav_page = "Documents"
    nav_page = st.radio("Navigation", ["Documents", "Chat", "Preview"],
                        label_visibility="collapsed")
    st.session_state.nav_page = nav_page
    
    # API base URL — env var for Docker, default for local dev
    API_BASE = os.environ.get("API_BASE", "http://localhost:8000")
    
    # Document selector (D-11) — populated from /api/v1/documents
    st.markdown("---")
    st.markdown("**Select Document**")
    try:
        resp = requests.get(f"{API_BASE}/api/v1/documents", timeout=5)
        if resp.status_code == 200:
            docs = resp.json().get("data", {}).get("documents", [])
            doc_options = {f"{d['filename']} (ID: {d['id']})": d['id'] for d in docs}
            if doc_options:
                selected = st.selectbox("", list(doc_options.keys()), label_visibility="collapsed")
                st.session_state.selected_doc_id = doc_options[selected]
                st.session_state.selected_doc_name = selected.split(" (ID:")[0]
            else:
                st.info("No documents uploaded yet")
    except requests.ConnectionError:
        st.warning("Backend not reachable")
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Streamlit→API | HTTP requests from Streamlit frontend to FastAPI backend over localhost |
| API→Filesystem | PDF file uploads stored in data/documents/, FAISS index in data/index/ |
| API→SQLite | Metadata queries via MetadataStore |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-3-01 | Tampering | POST /api/v1/documents/upload | mitigate | Validate content_type starts with "application/pdf"; reject non-PDF files with 400; limit file size (50MB max) to prevent disk overflow |
| T-3-02 | Denial of Service | PDF processing pipeline | mitigate | Run Indexer.process_document() via BackgroundTasks (non-blocking); timeout set at API level (30s default) |
| T-3-03 | Spoofing | All endpoints | accept | Single-user local app — no authentication for MVP. Production would add API key/auth middleware. |
| T-3-04 | Information Disclosure | GET /api/v1/documents | accept | Single-user local deployment — all documents belong to same user. No multi-tenancy for MVP. |
| T-3-05 | Elevation of Privilege | File path traversal in upload | mitigate | Use `os.path.basename()` on filename before joining with `data/documents/` path; reject filenames containing ".." or "/" |
</threat_model>
