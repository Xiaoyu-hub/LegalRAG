<objective>
Add document_id post-filtering to the generation pipeline and chat endpoint.

**Purpose:** Per D-10 and D-13, the chat endpoint receives a `document_id` from the frontend but currently ignores it during retrieval. The hybrid search retrieves chunks across ALL documents, then the generation pipeline answers using all of them. The fix: after hybrid search retrieves top-K chunks, filter to only those matching the requested `document_id` before passing to the LLM.

**Output:** Updated `backend/generation/pipeline.py` + `backend/api/chat.py`.
</objective>

```python
def answer_stream(self, query: str):
    """Stream answer tokens, then yield source data."""
    chunks = []
    if self.retriever is not None and self.metadata_store is not None:
        results = self.retriever.retrieve(query, top_k=5)
        if results:
            chunk_ids = [r[0] for r in results] if isinstance(results[0], tuple) else results
            chunks = self.metadata_store.get_chunks(chunk_ids)
    self.last_chunks = chunks
    system_prompt, user_prompt = self.prompt_builder.build(query, chunks)
    for token in self.generator.generate_stream(system_prompt, user_prompt):
        yield token
```
