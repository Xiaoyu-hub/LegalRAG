    Wait — this is wrong. Let me reconsider. The valid_pairs set should handle the case where a chunk has article+section AND the case where a chunk has article only. Both need to be added. Let me think again...

    Actually, D-16 says: "Two-level validation: exact match (article + section pair) → partial match (citation text substring appears in any retrieved chunk's metadata)." This means:

    1. First try exact match: does (article, section) exist in any chunk's (article, section) pair?
    2. If exact match fails, try partial match: does the citation text (e.g., "[Article I]") appear as a substring in any chunk's metadata fields?

    So the validate method needs a two-pass approach:

    ```python
    def validate(self, citations, chunks):
        # Build valid pairs from chunks
        exact_pairs = set()
        partial_texts = set()
        
        for chunk in chunks:
            article = chunk.article or ""
            section = chunk.section or ""
            if article:
                article_clean = article.replace("Article ", "").strip()
                section_clean = section.replace("Section ", "").strip()
                exact_pairs.add((article_clean, section_clean))
                # Also add article-only variant for partial matching
    ```

    Hmm, this is getting complex. Let me simplify based on what D-16 actually says:

    "Two-level validation: exact match (article + section pair) → partial match (citation text substring in chunk metadata)"

    This means for each citation:
    1. Check if the (article, section) pair matches any chunk's (article, section) → valid
    2. If not, check if the citation text (like "[Article I]") appears as a substring in any retrieved chunk's metadata (article, section, title fields concatenated) → valid

    The key insight is that partial matching means: does the citation text literally appear somewhere in the chunk's metadata? This handles cases where the LLM writes "[Article I]" but the chunk metadata says "Article I, Section 1" — the substring "[Article I]" would match within that.

    Here's the implementation plan:

    ```python
    def validate(self, citations, chunks):
        valid_pairs = set()
        for chunk in chunks:
            article = chunk.article or ""
            section = chunk.section or ""
            if article:
                article_clean = article.replace("Article ", "").strip()
                section_clean = section.replace("Section ", "").strip()
                valid_pairs.add((article_clean, section_clean))

        for citation in citations:
            # Level 1: Exact match (article + section pair)
            if (citation.article, citation.section) in valid_pairs:
                citation.valid = True
                continue

            # Level 2: Partial match — citation text substring in any chunk's metadata
            citation.valid = self._partial_match(citation, chunks)

        return citations

    def _partial_match(self, citation, chunks) -> bool:
        """Check if citation text appears as substring in any chunk's metadata."""
        citation_lower = citation.text.lower()
        for chunk in chunks:
            chunk_meta = " ".join(filter(None, [
                chunk.article or "",
                chunk.section or "",
                chunk.title or "",
            ]))
            if citation_lower in chunk_meta.lower():
                return True
        return False
    ```

    This cleanly separates the two levels.
