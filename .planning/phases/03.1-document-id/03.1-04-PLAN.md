<objective>
Add `get_all_documents()` to MetadataStore and refactor documents.py to eliminate raw SQLite queries.

**Purpose:** Per D-11 and D-12, the documents API currently bypasses MetadataStore by doing raw SQLite queries directly (import sqlite3 at line 9, _get_all_documents and _get_chunk_count_by_doc_id helper functions). This breaks encapsulation and creates a maintenance burden. All DB access should go through MetadataStore methods.

**Output:** Updated `backend/storage/metadata_store.py` + `backend/api/documents.py`.
</objective>
